 Online Ticket Booking Analysis - Power BI Project

## 📊 Project Overview
This project analyzes 2000+ online ticket bookings to understand customer behavior, revenue patterns, and cancellation reasons using Power BI.

Dataset: Online_ticket_booking_Analysis.xlsx (2000 Rows)

## 📈 Dashboard - Page 1: Booking Performance Overview
- Total Bookings: 2K
- Total Revenue: 5M
- Avg Ticket Price: 2.5K
- Cancellation Rate: 11.17%
- Booking Failure Rate: 4.92%

Charts:
1. Count of Booking by Booking_Status (Confirmed 78.81%)
2. Count by Ticket_Type (Flight, Train, Bus)
3. Monthly Booking Trend
4. Total Revenue by Ticket_Type (Flight - 58.49%)
5. Cancellation Reasons
6. Payment Method vs Booking Status

## 📈 Dashboard - Page 2: Detailed Analysis
- Top 8 Busiest Routes (Bhopal-Delhi is No.1)
- Customer Age Group Analysis (56+ age group is 29.15% - Highest)
- Seat Type & Ticket Category Analysis
- Discount Offered vs Revenue (0% discount = 37% revenue)
- Complete Data Table

## 💡 Key Insights Found
1. Discount is not working: 0% discount gave highest revenue 1.83M
2. Senior Citizens (56+) are booking more tickets
3. Payment gateway issue: Cash and UPI have highest failures
4. Flight tickets generate 58.49% of total revenue
